# Fixture „minimal"

Eine einzelne Person mit genau einem Namen, ohne jede Beziehung — der kleinstmögliche gültige
Baum. Trägt jeden Test, der grundsätzlich prüft, dass eine Datenbank mit nur einer Person klaglos
geladen, angezeigt und durchsucht werden kann, ohne dass Layout, Zyklusprüfung oder
Ableitungsvergleich an fehlenden Beziehungen scheitern (Randfall "kein Baum, nur ein Blatt").
